# Awarexone Web (Frontend Only)

Next.js 14 + TypeScript + Tailwind + shadcn/ui. UI/UX matches the Awarexone PDFs. Data uses local JSON in `app/_data`.

## Run npm install
pnpm install
pnpm dev

## Structure
App Router with pages for home, lost/found/scams (index, detail, report wizards), education, auth, verify, and dashboard.
